# Messy Python Code Improvement

## Description
This project demonstrates how an unstructured Python
program can be improved through code refactoring.

## Files
- messy.py: Original unstructured program.
- improved.py: Refactored and readable program.

## Technologies
- Python 3

## How to Run
Run either file using:

python messy.py
python improved.py

## Improvements
- Better formatting and indentation
- Meaningful function and variable names
- Input validation
- Error handling
- Improved readability and maintainability
